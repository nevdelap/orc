# Review: task-015-2

## Findings

### R001

Status: ADDRESSED

The new regression test does not prove that terminal capture occurs before
Textual startup. It passes unchanged against the parent implementation, which
captured the terminal in `on_mount()` instead of the constructor. The test
constructs the app, then calls `on_mount()`, but it never changes or inspects
TTY state between those points and therefore cannot distinguish the old and
new behavior.

Evidence:

- `tests/test_task015.py:test_constructor_captures_terminal_before_textual_startup`
  records one `tcgetattr()` call only after both construction and `on_mount()`
  have completed.
- `git show HEAD^:orc` contains the old `on_mount()` capture and would satisfy
  the same assertions.
- The independent real-PTY probe on the reviewed source reported
  `ECHO_RESTORED True` and `ICANON_RESTORED True`, so the product behavior is
  observed, but the committed regression test does not protect it.

Resolution:

- The test now replaces `tcgetattr()` after construction with simulated
  Textual attributes and asserts that the constructor's original snapshot is
  retained. The old parent implementation fails the test because its
  `on_mount()` capture sees the replacement attributes.

Evidence:

- `tests/test_task015.py:test_constructor_captures_terminal_before_textual_startup`
  passes on the amended commit and distinguishes constructor capture from
  mount capture.
- The independent real-PTY probe reported `ECHO_RESTORED True` and
  `ICANON_RESTORED True`.

### R002

Status: ADDRESSED

The implementation plan has no `TASK-015-2` entry; `TASK-015` is already
`COMPLETED`, so this follow-up must use the required `TASK-EXTRA` contract for
directed out-of-plan work.

Evidence:

- The previous review snapshot used a nonconforming `TASK-015-2` subject and
  blank-separated `Implemented:` list; the amended commit now uses
  `TASK-EXTRA: restore caller terminal state` and contiguous list items.
- `design_docs/implementation_plan.md` defines `TASK-015` as completed and
  contains no `TASK-015-2` task, as required for an extra commit.
- `design_docs/agent_workflow.md` requires task commits to implement one plan
  entry, requires directed out-of-plan work to use `TASK-EXTRA`, and requires
  each review item to name `review_docs/<task-id>.md` and a finding ID.

Resolution:

- The amended commit is explicitly directed by the user's bounded terminal
  restoration request, uses the valid `TASK-EXTRA` subject, preserves the
  model trailer, and has conforming `Implemented:` and `Reviewed:` sections.

## Final decision

Status: COMPLETED

R001 and R002 are addressed. The TASK-EXTRA commit is approved.
